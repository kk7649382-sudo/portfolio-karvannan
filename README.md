# G_K Karvannan - Personal Portfolio

A sleek, modern, dark-themed personal portfolio homepage built with clean semantic HTML5, modern CSS3 (custom properties, glassmorphism, responsive grid), and vanilla JavaScript.

## Features
- **Theme**: Cool obsidian/cyber dark theme with ambient cyan/purple glow gradients and grid pattern.
- **Hero Section**:
  - Interactive terminal card with live typewriter animation.
  - Quick action buttons ("Get in Touch", "Explore Skills").
  - Social media links (GitHub, LinkedIn, Email).
- **01 // About Me**:
  - Background story as a student and aspiring software engineer.
  - Highlights list (Academic focus, Engineering philosophy, Current objective).
  - Quick metrics & interest tags.
- **02 // Technical Skills**:
  - Filterable skill cards: **All**, **Languages**, **Web & Frameworks**, and **Tools & Core**.
  - Animated proficiency indicators.
- **03 // Contact**:
  - Contact cards with single-click "Copy Email" button & toast confirmation.
  - Functional interactive contact form mockup with submission feedback.
  - Direct links to GitHub & LinkedIn.
- **Responsive**: Fully optimized for mobile, tablet, and widescreen monitors.

## How to View
Double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Brave).
Alternatively, you can run a local server in PowerShell:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Customization
- Open `index.html` to update your email, GitHub link, LinkedIn URL, and bio text.
- Open `style.css` to tweak accent colors (`--accent-cyan`, `--accent-purple`).
